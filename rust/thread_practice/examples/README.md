### 1번: join으로 결과 모으기 버전
#### 문제
- 스레드 5개를 띄운다
- 각 스레드는 0~99 사이 랜덤 정수를 몇 개(예: 10개 뽑아서 그 합을 계산하고, 자기 스레드의 부분합을 리턴한다)
- 메인 스레드는 5개의 JoinHandle을 모아뒀다가 join()으로 각 부분합을 받아서 전체 합을 출력한다

막힐 만한 지점: 랜덤 숫자 생성용 크레이트(rand) 추가하는 법, 클로저에서 move 필요 여부, join() 리턴 타입 처리

### 2번: Arc<Mutex<i32>>로 공유 합계에 직접 더하기
- 스레드 5개를 띄운다
- 각 스레드는 이번에도 0~99 사이 랜덤 정수 10개를 뽑아 부분합을 계산한다
- 근데 이번엔 그 부분합을 리턴하지 않고, Arc<Mutex<i32>>로 감싼 공유 변수에 직접 더한다
모든 스레드가 끝난 뒤 메인에서 그 공유 변수의 최종값을 출력한다

막힐 만한 지점: 이번엔 "1씩 더하기"가 아니라 "각자 계산한 부분합을 더하기"라는 점이 다르니 lock을 언제, 몇 번 걸건지 체크
